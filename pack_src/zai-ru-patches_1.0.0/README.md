# zai-ru-patches 1.0.0

Патч-слой русификации модпака zai-pack.

## Принцип

- Только строки, отсутствующие в `locale/ru` оригинальных модов.
- Если у мода есть собственная русская локаль — мы её не дублируем.
- Файл `locale/ru/locale.cfg` — накопительный: для каждого мода отдельный раздел.

## Что переведено в 1.0.0

| Мод | Что |
| --- | --- |
| `space-exploration` (частично) | Космические поезда |
| `loaders-modernized` | Загрузчики трёх уровней |
| `TerrainEvolution2` | Технологии, описание |
| `Peppermint Mining` | Предмет, сущность, технология |

## Расширение

Добавляйте переводы в `locale/ru/locale.cfg` по секциям:

```ini
[technology-name]
some-tech-name=Перевод имени технологии

[item-description]
some-item-name=Перевод описания предмета
```

Factorio автоматически применит эти строки, перекрывая английские из
оригинального мода (если у него нет русской локали).
